## Refusal, uncertainty and context changes

- Wrong owner, missing private identity, wrong retained pin and invalid profile:
  reject before credential or Git execution; show static diagnostics only.
- Refused/different existing PAT: no replacement and no subsequent Git submission.
- Lost credential reply or Git handoff reply: warning must say a credential may
  already be installed; do not retry, rotate, create another worker or infer rollback.
- Change selected environment/config/session between preview and confirmation:
  discard preview and clear token; core full snapshot must independently reject drift.
- Change selection or close/reopen while mutation is pending: preserve an
  unattributed unknown warning, never show a result against the newly selected row.
- Repeated clicks and concurrent Inspect/Stop/reconnect/task-start attempts:
  one in-flight repository operation; no implicit duplicate submission.
- Absent, claimed-unknown, error and complete-with-reason receipts remain distinct
  from successful completion. Original completion is not current task readiness.
