# Original producer Restricted Gate qualification

## 1. Purpose

Qualify original opaque-stream DNS/tag admission and preserve Main TCP bounds.
This procedure contains no execution result and authorizes no infrastructure.

## 2. Applicability

Use the exact candidate Worker with `trusted-exposure-gate` enabled. Normal
features stay unchanged. Read the trusted-exposure-gate and trusted-tcp-producer
boundaries and the existing worker-exposure-gate procedure. The actual adapter
requires the separately qualified original Producer; it grants no native approval.

## 3. Safety

> **CAUTION:** USE ONLY THE EXACT OWNED DAEMON, MAPPING AND PEER IN THE APPROVED WINDOW.
> The component binds root-managed ports and deletes no provider or foreign mapping.

No Auth/key/node/policy, rental, ordinary desktop daemon or production-device
operation is authorized here. A separate reviewed equipment plan must retain
original external mapping/daemon cleanup custody and hard runtime bounds.

## 4. Equipment and preconditions

- Current normal/test Worker artifacts with actual compiler/source/feature proof.
- Offline unit fixtures with private HOME/TMP/XDG and no desktop session/credentials.
- For actual tests only: original root-managed daemon at its fixed Runtime socket,
  immutable process/enrollment binding and original externally owned V20000→private
  Unix B20032 mapping using the pinned Unix Serve PROXY-v1 runtime with explicit `--horizon-flow-cancel`; no owned-Serve Rust adapter or restored metadata substitution.
- A separate actual owned tailnet peer with recorded real full DNS, tags, StableID
  and source addresses. The root caller must retain current actual mapping facts.
- Exclusive owned P20001, V20000 and target18080. B20032 selects the root-private
  Producer socket filename; no TCP B listener or backend publication is allowed.

## 5. Setup

1. Record source, exact normal/test artifacts, mode, request and original custody.

   Result: Pending Producer dependency and actual merged base remain distinct.
   Actual Kernel and Worker/userspace modes have separate retained bindings.

2. Build the current local tests after source review.

   ```bash
   RUSTFLAGS="-D warnings" cargo test -p horizon-cloud-worker --features trusted-exposure-gate --no-run --locked
   ```

   Result: Main Gate and adapter cases compile; no default/public activation occurs.

## 6. Tasks

### 6.1 T01 — Offline Main and adapter contracts

1. Run the full Gate filter, including Main budget/grace cases, without ignored tests.

   ```bash
   RUSTFLAGS="-D warnings" cargo test -p horizon-cloud-worker --features trusted-exposure-gate exposure_gate:: --locked
   ```

   Result: Main conservative charges, half-close, draining, source retention,
   close/JoinError and cancellation regressions remain. New tests cover exact
   original pending/accepted cookie comparison and foreign-cookie refusal, retained
   weak-handle drop and cancellation across the transport transition, original
   opaque socket buffer bounds, direct spoof/mixed CIDR rules, pending capacity,
   no pre-identity target/payload, error/timeout/phase/cancel and unpolled abort.
   Original control EOF without DRAINED0x01+EOF cancels even while payload input remains open.
   Normal and budget completion must wait for acknowledgement under unchanged deadlines, including a slow payload reader and interrupted ack-stage case.
   Explicit cancellation with retained Arcs must close the original control immediately.
   Private State transport fixtures also run the actual shared Unix↔TCP relay
   through request/response EOF, delayed budget response, unread reverse input,
   explicit cancellation and pending-identity budget wake. These fixtures issue
   no opaque peer, StableID, WhoIs fact or named admission; positive identity
   remains an actual-daemon requirement.

2. Run Producer tests, required tiers, CI command contracts and paired guidance checks.

   Result: Linux libs runs the adapter once after Producer; non-Linux and UI/speech
   shards omit it. Its failure still runs later checks and fails the shard.
   Existing SDK/gateway/Owner/encoder commands are preserved.

### 6.2 T02 — Actual named allow and deny, each daemon mode

> **CAUTION:** BIND ONLY THE FOUR DECLARED OWNED COMPONENT PORTS IN THE APPROVED LIFECYCLE.
> Retain the original mapping supervisor until positive close and resource reconciliation.

1. For each original Kernel and Worker/userspace binding, supply a bounded
   Restricted policy JSON with target_port18080 and `HORIZON_TRUSTED_GATE_POLICY`.
   Set `HORIZON_TRUSTED_GATE_COMPONENT` to `task-owned-kernel` or
   `task-owned-worker`, and `HORIZON_TRUSTED_GATE_EXPECT` to `allow` or `deny`.
   Set `HORIZON_TRUSTED_GATE_EXPECTED_PEER_ID` to the separate peer's actual
   captured StableID. This is a test expectation, never source authority.
   Invoke only the reviewed ignored selector in the exact frozen test executable:

   ```text
   exposure_gate::tests::trusted_adapter::actual_task_owned_named_admission_uses_the_original_opaque_peer
   --exact --ignored --nocapture
   ```

   Result: Genuine original Producer pin owns its private Unix listener; the Gate
   binds P exclusively and never binds TCP B. A root local forged Unix PROXY
   connection lacks original daemon credentials, reaches no target and produces zero verified
   opaque peers. The ready marker reports `backend:unix` for equipment synchronization, not a public URL.

2. From the same real peer, connect through the original V mapping. Run separate
   DNS-only allow, tag-only allow, wrong-full-name deny, absent-tag deny and
   mixed CIDR/name/tag cases. Record the actual policy and observed peer separately.

   Result: Allow sends PING, reads PONG, sends DONE and half-closes its write side;
   the target observes exact bytes/EOF and half-closes its response. Deny receives
   no target connection. Both must observe a genuine Producer-issued opaque peer
   matching the registered original socket and otherwise eligible for admission;
   missing data, capacity/timeout or custody refusal cannot
   pass the named-denial case. A fake header cannot satisfy this observation.
   Exactly one genuine opaque peer must match that captured StableID; another
   flow cannot supply the policy-denial observation.
   Allow also waits for inactive original flow state before Gate close.
   Exactly one normal completion follows original DRAINED plus EOF, with 12 charged
   and forwarded bytes. The selector emits `horizon-trusted-gate-normal-drained=1`
   before close; an immediate close cannot supply this evidence.

3. Complete original Gate close and original external mapping cleanup.

   Result: Active/pending streams close, all flows and Producer children retire;
   exact owned listeners/processes are absent. External cleanup is not inferred
   from Gate counters or a typed peer. Preserve all raw allow/deny/failure records.
